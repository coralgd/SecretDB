# SecretDB

Локальное приложение на HTML/CSS/JS с системой аккаунтов и доступами.

## Что есть

- вход и регистрация аккаунтов;
- роль модератора (по умолчанию `admin / admin123`);
- панель модератора для выдачи/снятия доступа к выбранной БД и разделу;
- отдельные права на базы и разделы для аккаунтов;
- разделы с ключом доступа и без ключа;
- создание и удаление баз/разделов модератором;
- поиск по записям;
- импорт JSON;
- хранение данных в `localStorage`.

## Запуск

Открой `index.html` в браузере.
