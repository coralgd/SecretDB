# SecretDB

Мини-приложение на чистом HTML/CSS/JS для локальной работы с "секретными" базами данных:

- создание нескольких баз данных c ключом удаления;
- удаление базы только после ввода корректного ключа удаления;
- создание разделов внутри каждой базы;
- разделы могут быть как с ключом доступа, так и без ключа;
- добавление записей только после успешного ввода ключа (или сразу для разделов без ключа);
- сохранение структуры в `localStorage`.

## Запуск

Просто откройте `index.html` в браузере.

> Следующий шаг: можно заменить `localStorage` на Firebase (Firestore/Auth) и перенести ключи доступа в защищённую серверную логику.
