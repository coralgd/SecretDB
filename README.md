# SecretDB

Нормальная и простая версия локальной «секретной» базы на чистом HTML/CSS/JS.

## Возможности

- несколько баз данных;
- ключ удаления для каждой базы;
- разделы внутри базы (с ключом или без ключа);
- просмотр/добавление записей после открытия раздела;
- быстрый поиск по записям;
- импорт JSON;
- хранение в `localStorage`.

## Запуск

Открой `index.html` в браузере.
