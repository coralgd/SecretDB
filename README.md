# SecretDB

Прокачанный локальный прототип «секретной» базы на чистом HTML/CSS/JS.

## Что умеет сейчас

- создание нескольких баз с **ключом удаления**;
- удаление базы только по правильному ключу;
- создание разделов с ключом и без ключа;
- доступ к разделам по ключу (или сразу, если ключ пустой);
- добавление записей с датой создания;
- поиск по записям внутри открытого раздела;
- быстрые действия: очистка поиска, повторная блокировка, полная очистка раздела;
- **Security HUD** со статистикой по защищённости;
- **авто-блокировка** защищённых разделов по таймеру бездействия;
- импорт данных из JSON;
- сохранение в `localStorage`.

## Запуск

Открой `index.html` в браузере.

## Дальше

На следующем этапе можно подключить Firebase (Firestore + Auth + Cloud Functions), чтобы хранить и проверять ключи на серверной стороне.
